# 知识点具体内容 HTML 文件夹说明文档

本目录用于存放所有小学数学知识点的独立 HTML 精讲讲义文件。当在 Web 应用中点击知识点时，右侧将通过 `iframe` 自动加载路径为 `./knowledge/知识点名称.html` 的文件。

---

## 📁 目录结构与命名规则

### 1. 文件存放位置
所有具体知识点 HTML 文件直接存放在本目录（即 `/public/knowledge/`）：
```
/public/knowledge/
  ├── 认识10以内的数字.html
  ├── 20以内的进位加法.html
  ├── 鸡兔同笼.html
  ├── 正方形和长方形的周长.html
  ├── 圆柱的表面积.html
  ├── ...（共241个知识点）
  ├── templates/
  │    └── knowledge_template.html （标准讲义空白模板）
  └── README.md （本说明文件）
```

### 2. 文件命名规范（至关重要）
- 文件名必须与知识点名称**完全一致**，扩展名为 `.html`。
- 例如：
  - 知识点名称：`认识10以内的数字` $\to$ 文件名：`认识10以内的数字.html`
  - 知识点名称：`鸡兔同笼` $\to$ 文件名：`鸡兔同笼.html`
  - 知识点名称：`三位数加三位数（连续进位）` $\to$ 文件名：`三位数加三位数（连续进位）.html`

## 🚀 如何上传与替换内容？

### 方式一：在网页应用内直接点击“上传/编辑讲义”
1. 打开 Web 应用进入学习详情页；
2. 点击右上角的 **“上传讲义”** 或 **“编辑知识点”** 按钮；
3. 选择您本地编辑好的 `.html` 文件，或者直接在弹窗内粘贴 HTML 代码；
4. 点击“保存生效”，系统将自动保存并即时刷新右侧预览。

### 方式二：直接在代码工作区拷贝或上传文件
1. 将编写好的 HTML 文件重命名为对应的知识点名称（如 `鸡兔同笼.html`）；
2. 放入本项目的 `/public/knowledge/` 文件夹下；
3. 重新进入页面即可实时加载您的专属微课讲义。

## 📝 推荐 HTML 标准讲义结构（可参考 templates/knowledge_template.html）
每个讲义文件建议包含以下四大核心模块：
1. **核心概念与算理法则**（公式、单位、定义）
2. **学霸记忆口诀**（朗朗上口的口诀、速算技巧）
3. **经典例题与分步解答**（带思路分析的典型题目）
4. **随堂小测与自查答案**（互动式答题按钮）
5. **已掌握同步按钮**（触发 `window.parent.postMessage({ type: 'TOGGLE_LEARNED_FROM_IFRAME', name: '...' }, '*')` 自动勾选主系统已学状态）
